### День 2 (19 ноября): Ядро сессии и Прогрессивная система (State Machine)
- [ ] **Таймер сессии:** Реализация базового таймера (52 мин).
- [ ] **Уведомления вне окна:** Web Notifications API, Web Audio API (звук в фоне), Page Visibility API + мигание `document.title`.
- [ ] **Логика «Долга здоровья» (State Machine):**
  - *Уровень 0:* Стандартное уведомление.
  - *Триггер:* 5 мин игнора ИЛИ кнопка «Не могу» -> Уровень 1. Таймер работы сокращается (x0.6), отдых увеличивается.
  - *Уровень 2:* Таймер работы сокращается (x0.3). Жесткие уведомления.
  - *Сброс:* Кнопка «Отметился» возвращает к Уровню 0.

- [ ] **Расчет Health ROI:** Реализация формулы `(breaks_done * 15) - (breaks_missed * 25)`. Ограничение от 0 до 100.
