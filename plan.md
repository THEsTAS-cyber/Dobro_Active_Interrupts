### 21 ноября: Данные, лендинг, ядро
- [ ] **JSON-справочники** в `public/data/`:
  - `health-issues.json` — 6–7 проблем (шея, глаза, спина, запястья, осанка, стресс, общее утомление).
  - `exercises.json` — 20–30 упражнений: `id`, `title`, `description`, `duration_sec`, `issue_id`, `urgency_level`, `contraindications`.
  - `tips.json` — советы для экрана статистики.

- [ ] **Лендинг (п. 4.1, 30 баллов):** проблема (2–4 факта со ссылкой на источник, без выдуманных цифр), аудитория, решение в 3 шага, медицинский дисклеймер.
- [ ] **Онбординг:** чекбоксы «болевых точек» → `localStorage` (`dab.v1.healthProfile`).
- [ ] **State Machine** (`utils/stateMachine.js`, чистая функция `nextState(state, event)`):

  | Уровень | Работа | Упражнений | Отдых |
  |---|---|---|---|
  | 0 — Норма | 52 мин | 1–2 | 5 мин |
  | 1 — Долг | ×0.6 ≈ 31 мин | 3 | 10 мин |
  | 2 — Критический | ×0.3 ≈ 15 мин | 4–5 | 15 мин |

  - `CHECKED_IN` («Отметился») → уровень 0, `breaksDone +1`.
  - `CANT` («Не могу») или `IGNORE_TIMEOUT` (5 мин без ответа) → уровень +1 (максимум 2), `breaksMissed +1`.
- [ ] **Таймер по меткам времени:** `deadline − Date.now()`, пересчёт на `visibilitychange`; состояние сессии в `localStorage` (переживает перезагрузку).
- [ ] **Демо-режим** (переключатель в UI + `?demo=1`): 52 мин → 20 сек, 5 мин игнора → 15 сек.
- [ ] **Выборка упражнений:** фильтр по `issue_id` (профиль) и `urgency_level` (State Machine).
- [ ] **Сессии в localStorage:** `dab.v1.sessions` — `{id, date, duration, breaksDone, breaksMissed, healthScore}`; обработка `QuotaExceededError` и битого JSON.

### 22 ноября: Уведомления, Health ROI, экспорт, WCAG, документация
- [ ] **Уведомления вне окна:**
  - Web Notifications API — запрос прав **по клику** «Начать сессию»; при отказе — баннер, работаем на звуке + title.
  - Web Audio API — `AudioContext` создать/`resume()` по клику «Начать сессию».
  - Page Visibility API + мигание `document.title` «⏰ Пора отдохнуть! | Активные перерывы».
  - Vibration API для уровня 2 — с проверкой `'vibrate' in navigator` (в iOS Safari нет).
- [ ] **Health ROI:** `clamp(breaksDone × 15 − breaksMissed × 25, 0, 100)`; прогресс-бар `role="progressbar"` + «Вы сохранили X% дневного ресурса».
- [ ] **Экспорт/импорт:**
  - JSON `{ schemaVersion: 1, exportedAt, healthProfile, sessions }`; CSV (только `sessions`, UTF-8 с BOM).
  - Импорт с валидацией: версия схемы, типы, даты, `healthScore` 0–100, дедупликация по `id`, итог «Импортировано N, пропущено M», подтверждение перед заменой.
- [ ] **Страница «Для жюри»** (`#/jury`): таблицы содержимого `localStorage`, ссылки на JSON-справочники, «Заполнить демо-данными», «Очистить».
- [ ] **WCAG (п. 4.3):** Tab/Shift+Tab, `:focus-visible`, ловушка фокуса и `Esc` в модалках, `aria-live="polite"` для таймера, контраст ≥ 4.5:1, Lighthouse Accessibility ≥ 95.
- [ ] **Адаптивность:** mobile-first; проверить 360 px, планшет, десктоп.
- [ ] **Документация:** `README.md`, `ARCHITECTURE.md`, `PROGRESS.md` (только реальные записи).
- [ ] **Финальный тест на публичной ссылке:** демо-режим, вкладка в фоне → пуш + звук + мигание title.

### Если не успеваем — приоритет
1) рабочий деплой → 2) лендинг (4.1) → 3) State Machine + демо-режим → 4) клавиатура/WCAG → 5) экспорт/импорт → 6) уведомления вне окна → 7) полировка. После каждого пункта — деплой.
