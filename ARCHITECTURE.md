# Архитектурные решения (ADR)

## ADR-1. Отказ от серверной БД в пользу JSON + localStorage

**Контекст.** Правила конкурса разрешают Firebase, Supabase, MySQL или SQLite, но требуют предоставить жюри полный доступ к БД; если доступа нет, снимается до 10 баллов (п. 3.3). Внешние облачные БД могут быть недоступны или работать нестабильно в РФ, а бесплатные тарифы «засыпают» при простое. Сайт размещается на GitHub Pages — это статический хостинг без серверной части.

**Решение.** Справочники (проблемы, упражнения, советы) хранятся как статические JSON-файлы в `public/data/` и загружаются через `fetch`. Пользовательские данные (профиль, история, активная сессия, настройки) хранятся в `localStorage` под версионированными ключами `dab.v1.*` через обёртку `src/utils/storage.js`, которая обрабатывает `QuotaExceededError`, недоступность хранилища и повреждённые значения. Для переноса данных реализованы экспорт/импорт JSON и CSV с валидацией (`src/utils/exportData.js`). Всё хранилище открыто жюри на странице `#/jury`.

**Альтернативы.**
- *Supabase / Firebase* — настоящая БД, но риск блокировок и «засыпания», нужен доступ жюри и ключи в клиентском коде.
- *SQLite через sql.js (WASM)* — разрешена правилами и работает на Pages без сервера; отложено как возможное улучшение для финала (+~1 МБ к загрузке).
- *IndexedDB* — больше объём, но сложнее API, а объём данных (сотни записей) этого не требует.

**Последствия.** 100% аптайм вместе с хостингом, приватность (данные не покидают устройство), мгновенная работа. Минус — данные привязаны к браузеру; компенсируется экспортом/импортом. Объём истории ограничен 500 сессиями.

## ADR-2. HashRouter вместо BrowserRouter

**Контекст.** GitHub Pages не умеет отдавать `index.html` для произвольных путей: прямой заход или перезагрузка на `/Dobro_Active_Interrupts/session` вернёт 404.

**Решение.** `HashRouter` из React Router v6: маршруты имеют вид `#/session`, сервер всегда отдаёт `index.html`. `base: '/Dobro_Active_Interrupts/'` в `vite.config.js` совпадает с именем репозитория; пути к статике строятся от `import.meta.env.BASE_URL`.

**Альтернативы.** Хак с копированием `index.html` в `404.html` — работает, но сервер отвечает статусом 404, что хуже для проверки и индексации.

**Последствия.** Ссылки чуть менее красивые, зато любая страница открывается напрямую и по перезагрузке. Внутристраничные якоря (`href="#how"`) в HashRouter конфликтуют с маршрутами, поэтому прокрутка к разделам сделана кнопками с переносом фокуса.

## ADR-3. Таймер на абсолютных метках времени + конечный автомат

**Контекст.** Браузеры замедляют таймеры в фоновых вкладках (до одного срабатывания в минуту), а пользователь большую часть времени работает в другой вкладке или программе. Счётчик «тиков» `setInterval` в таком режиме отстаёт на десятки минут.

**Решение.** Логика «долга здоровья» — чистая функция `transition(state, event, now, timings)` в `src/utils/stateMachine.js` (покрыта тестами). Состояние хранит абсолютный `deadline`; каждый тик и событие `visibilitychange` сравнивают `Date.now()` с дедлайном (`src/hooks/useSession.js`). Состояние сохраняется в `localStorage`, поэтому перезагрузка не сбрасывает сессию. Сессия живёт на уровне приложения (`SessionContext`), а не страницы — напоминания приходят на любой странице.

**Последствия.** Время всегда точное; в фоне напоминание может прийти с задержкой до ~1 минуты (ограничение браузера, указано в README). Демо-режим — это просто другой набор длительностей (`src/utils/config.js`).

## ADR-4. Web Audio API вместо тега `<audio>`

**Контекст.** Воспроизведение `<audio>` без жеста пользователя блокируется политиками автозапуска, особенно в фоновых вкладках. Нужен звук именно тогда, когда пользователь в другой вкладке.

**Решение.** `AudioContext` создаётся и «разблокируется» внутри клика «Начать сессию»; позже звуки синтезируются осцилляторами (`src/hooks/useNotifications.js`) — без аудиофайлов. Для каждого уровня свой паттерн: мягкий синус на уровне 0, тревожный квадратный сигнал на уровне 2. Там же в клике запрашивается разрешение на системные уведомления.

**Альтернативы.** Аудиофайлы (лишние запросы, риск блокировки), Service Worker + Push API (нужен сервер для пушей, избыточно для конкурса).

**Последствия.** Звук работает в фоне без внешних ресурсов; при закрытой вкладке напоминаний нет — это честно указано пользователю.
