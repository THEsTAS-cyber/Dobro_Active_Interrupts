## ℹ️ О проекте

### Проблема
По данным ВОЗ, **31% взрослых в мире (около 1,8 млрд человек)** двигаются меньше рекомендованного, а у недостаточно активных людей **риск смерти на 20–30% выше**. Большое время сидения связано с сердечно-сосудистыми заболеваниями, диабетом 2 типа и рядом видов рака. Офисная работа и учёба за компьютером — это часы почти без движения, а в потоке задач о перерывах легко забыть.

*Источник: [ВОЗ, информационный бюллетень «Физическая активность»](https://www.who.int/news-room/fact-sheets/detail/physical-activity).*

### Целевая аудитория
Офисные сотрудники, студенты и школьники, учебные и рабочие коллективы, которые хотят ввести привычку регулярных разминок.

### Решение
1. **Профиль здоровья** — пользователь отмечает, что беспокоит (шея, глаза, спина, запястья, осанка, стресс, утомление), и получает упражнения под себя.
2. **Таймер сессии с «долгом здоровья»** — напоминания становятся настойчивее, если перерывы пропускаются.
3. **Напоминания вне окна** — системное уведомление, звук, вибрация и мигающий заголовок вкладки, даже если пользователь работает в другой программе.
4. **Health ROI** — в конце сессии видно, сколько процентов «дневного ресурса» удалось сохранить.

⚠️ Приложение не заменяет консультацию врача. У каждого упражнения указаны противопоказания.

### Прогрессивная система «Долг здоровья»

| Уровень | Когда наступает | Следующий перерыв | Упражнений | Отдых |
|---|---|---|---|---|
| 🟢 0 — Норма | Старт сессии или «Отметился» | через 52 мин | 1–2 лёгких | 5 мин |
| 🟠 1 — Долг | «Не могу» или 5 мин без ответа | через ~31 мин (×0.6) | 3 | 10 мин |
| 🔴 2 — Критический | Повторный пропуск | через ~16 мин (×0.3) | 5 + звук и вибрация | 15 мин |

**Health ROI** = `clamp(перерывы × 15 − пропуски × 25, 0, 100)`. Пропуск «стоит» дороже, чем приносит перерыв, — это мотивирует не пропускать.

## 🗄️ Работа с данными
Серверная БД не используется — это осознанное архитектурное решение (см. [`ARCHITECTURE.md`](ARCHITECTURE.md)): сайт работает на GitHub Pages без внешних сервисов, поэтому нет риска недоступности БД, а данные пользователя не покидают его устройство. Чтобы жюри могло полностью проверить работу с данными (п. 3.3), всё хранилище открыто на странице **«Для жюри»**.

### Где лежат данные

| Что | Где | Формат |
|---|---|---|
| Справочник проблем (7) | [`public/data/health-issues.json`](public/data/health-issues.json) | JSON |
| Каталог упражнений (27) | [`public/data/exercises.json`](public/data/exercises.json) | JSON |
| Советы (7) | [`public/data/tips.json`](public/data/tips.json) | JSON |
| Профиль здоровья | `localStorage` → `dab.v1.healthProfile` | `{ issues: string[] }` |
| История сессий | `localStorage` → `dab.v1.sessions` | массив сессий |
| Текущая сессия | `localStorage` → `dab.v1.activeSession` | состояние автомата |
| Настройки | `localStorage` → `dab.v1.settings` | `{ demo, sound }` |

Справочники доступны по прямым ссылкам: [health-issues.json](https://boopevdakov.github.io/Dobro_Active_Interrupts/data/health-issues.json), [exercises.json](https://boopevdakov.github.io/Dobro_Active_Interrupts/data/exercises.json), [tips.json](https://boopevdakov.github.io/Dobro_Active_Interrupts/data/tips.json).

### Структура
- **Упражнение:** `id`, `title`, `description`, `steps[]`, `duration_sec`, `issue_id` (ссылка на справочник проблем или `general`), `urgency_level` (0 — лёгкое, 1 — среднее, 2 — активное), `contraindications`.
- **Сессия:** `id` (уникальный ключ), `date` (ISO 8601), `duration` (мин), `breaksDone`, `breaksMissed`, `healthScore` (0–100).

### Целостность данных
- Ключи `localStorage` версионированы (`dab.v1.*`) — формат можно будет мигрировать.
- **`QuotaExceededError`:** старые сессии обрезаются, пользователь видит предупреждение.
- **Хранилище недоступно** (приватный режим): приложение работает и предупреждает, что данные не сохранятся.
- **Повреждённое значение** в `localStorage` заменяется значением по умолчанию — приложение не падает.
- Ссылочная целостность справочников (каждый `issue_id` существует, `id` уникальны) проверяется автотестом.

### Экспорт и импорт (File API)
- **«Скачать статистику (JSON)»** — `{ schemaVersion: 1, exportedAt, app, healthProfile, sessions }`.
- **«Скачать таблицу (CSV)»** — UTF-8 с BOM, корректно открывается в Excel с кириллицей.
- **«Загрузить статистику»** — JSON или CSV. Файл проверяется: версия формата, типы полей, даты, диапазоны (`healthScore` 0–100, перерывы — целые ≥ 0), дубликаты. Некорректные записи пропускаются с объяснением причины, `healthScore` пересчитывается по формуле. Перед изменением пользователь выбирает «Добавить к истории» или «Заменить историю».

## 🧪 Как тестировать
1. **Демо-режим:** откройте сайт с `?demo=1` или включите переключатель в подвале — работа 20 сек, ожидание ответа 15 сек.
2. **Профиль:** «Мой профиль» → отметьте, например, «Шея» и «Глаза» → «Сохранить».
3. **State Machine:**
   - «Сессия» → «Начать сессию», разрешите уведомления.
   - Через 20 сек откроется окно перерыва с упражнениями (уровень 0).
   - Нажмите **«Не могу сейчас»** → уровень 1, следующий перерыв раньше, 3 упражнения.
   - Нажмите «Сделать перерыв сейчас» и ничего не делайте 15 сек → уровень 2, 5 упражнений, резкий звук и вибрация.
   - Нажмите **«Отметился»** → возврат к уровню 0.
4. **Уведомления вне окна:** запустите сессию и переключитесь на другую вкладку — придут системное уведомление и звук, заголовок вкладки начнёт мигать «⏰ Пора отдохнуть!».
5. **Перезагрузка:** обновите страницу во время сессии — таймер продолжится с того же места.
6. **Health ROI:** «Завершить сессию» → страница статистики с прогресс-баром и историей.
7. **Данные:** «Для жюри» → «Заполнить демо-данными» → скачайте JSON/CSV → загрузите файл обратно.
8. **Без мыши:** всё выше проходится клавиатурой — `Tab`, `Shift+Tab`, `Enter`, `Пробел`, `Esc`.

**Ограничения браузеров:** без разрешения на уведомления работают звук и мигание заголовка; вибрации нет в iOS Safari; в фоновых вкладках браузер может задержать напоминание до ~1 минуты; при закрытой вкладке напоминания не приходят.

## ♿ Доступность (WCAG 2.1 AA)
- Полная навигация с клавиатуры, видимый фокус (`:focus-visible`), ссылка «Перейти к содержимому».
- При переходе между страницами фокус переносится на заголовок, обновляется `document.title`.
- Семантическая вёрстка: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, таблицы с `<caption>` и `scope`.
- Модальные окна: `role="dialog"`, `aria-modal`, ловушка фокуса, закрытие по `Esc`, возврат фокуса.
- Скринридеры: `aria-live="polite"` для объявлений о перерывах, `role="timer"`, `role="progressbar"` с `aria-valuenow`.
- Контраст текста ≥ 4.5:1, уровень срочности обозначается не только цветом, но и текстом с иконкой.
- Учитываются `prefers-reduced-motion` и режим высокой контрастности (`forced-colors`).
- Проверено axe-core: 0 нарушений на всех страницах.

## 🛠 Технологии
- **Frontend:** React 18 + Vite, JavaScript (ES6+), React Router v6 (`HashRouter`), обычный CSS без UI-библиотек и внешних шрифтов.
- **Данные:** JSON-справочники + `localStorage`, экспорт/импорт через File API.
- **API браузера:** Web Notifications, Web Audio, Page Visibility, Vibration, File API.
- **Хостинг:** GitHub Pages, автодеплой через GitHub Actions.
