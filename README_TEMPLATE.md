# 🟢 Активные перерывы | Проект для конкурса «Добрые Сайты 2026»

> Помогаем учебным и рабочим коллективам делать регулярные двигательные паузы — с умной системой напоминаний и персонализацией упражнений.

## 🚀 Быстрый старт (для жюри)
**Рабочая ссылка:** https://boopevdakov.github.io/Dobro_Active_Interrupts/
*Сайт полностью работает в браузере, установка дополнительного ПО не требуется (п. 3.2 Правил).*

**Проверить всё за 3 минуты:** откройте сайт с параметром `?demo=1` (или включите «Демо-режим» в интерфейсе) — 52 минуты работы сокращаются до 20 секунд.

## ℹ️ О проекте
- **Проблема:** [последствия сидячей работы — 2–4 факта со ссылками на источники]
- **Целевая аудитория:** офисные работники, студенты, учебные и рабочие коллективы.
- **Решение:** таймер перерывов с прогрессивной системой напоминаний («долг здоровья»), подбор упражнений под профиль, расчёт Health ROI.
- ⚠️ Приложение не заменяет консультацию врача. При острой боли упражнения не выполнять.

## 🗄️ Работа с данными
*Серверная БД не используется — осознанное решение (см. `ARCHITECTURE.md`): сайт работает на GitHub Pages без внешних сервисов, данные пользователя не покидают его устройство.*

| Что | Где | Формат |
|---|---|---|
| Справочник проблем | `public/data/health-issues.json` | JSON |
| Каталог упражнений | `public/data/exercises.json` | JSON |
| Советы | `public/data/tips.json` | JSON |
| Профиль здоровья | `localStorage` → `dab.v1.healthProfile` | JSON |
| История сессий | `localStorage` → `dab.v1.sessions` | JSON-массив |

Справочники доступны по прямым ссылкам:
- [health-issues.json](https://boopevdakov.github.io/Dobro_Active_Interrupts/data/health-issues.json)
- [exercises.json](https://boopevdakov.github.io/Dobro_Active_Interrupts/data/exercises.json)

**Как проверить работу с данными:**
1. Откройте страницу **«Для жюри»** (`#/jury`) — там таблицы с текущим содержимым хранилища и кнопка «Заполнить демо-данными».
2. **Экспорт:** «Скачать статистику» → JSON (`{ schemaVersion, exportedAt, healthProfile, sessions }`) или CSV (UTF-8, открывается в Excel).
3. **Импорт:** «Загрузить статистику» → файл проверяется (версия схемы, типы полей, даты, диапазон 0–100, дубликаты). Невалидные записи пропускаются с сообщением «Импортировано N, пропущено M».
4. **Устойчивость:** переполнение хранилища (`QuotaExceededError`) и повреждённые данные обрабатываются без падения приложения.

## 🧪 Как тестировать
1. **Демо-режим:** `?demo=1` — работа 20 сек, таймаут игнора 15 сек.
2. **Прогрессивная система (State Machine):**
   - Запустите сессию и дождитесь напоминания.
   - Нажмите **«Не могу»** или ничего не нажимайте → уровень 1: следующий перерыв раньше (×0.6), 3 упражнения.
   - Повторите → уровень 2: ×0.3, 4–5 упражнений, резкий звук и вибрация (на поддерживающих устройствах).
   - Нажмите **«Отметился»** → возврат к уровню 0.
3. **Уведомления вне окна:** запустите сессию, переключитесь на другую вкладку → системное уведомление, звук, мигающий заголовок вкладки.
4. **Без мыши:** весь сценарий проходится клавиатурой (`Tab`, `Shift+Tab`, `Enter`, `Space`, `Esc`).

**Ограничения браузеров:** уведомления требуют разрешения (при отказе работают звук и заголовок); вибрация недоступна в iOS Safari; при закрытой вкладке напоминания не приходят.

## 🛠 Технологии
- **Frontend:** React (Vite), JavaScript (ES6+), React Router v6 (`HashRouter`)
- **Данные:** JSON-справочники + `localStorage`, экспорт/импорт через File API
- **Хостинг:** GitHub Pages
- **API браузера:** Web Notifications, Web Audio, Page Visibility, Vibration, File API

## ♿ Доступность (WCAG)
- Полная навигация с клавиатуры, видимый фокус (`:focus-visible`).
- Семантическая вёрстка (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), skip-link.
- Модальные окна: ловушка фокуса, закрытие по `Esc`.
- Скринридеры: `aria-label`, `aria-live="polite"` для таймера, `role="progressbar"` для Health ROI.
- Контраст текста не ниже WCAG AA (4.5:1).
